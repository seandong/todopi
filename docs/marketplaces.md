# Marketplaces and registries

`todopi setup <agent>` is the supported way to connect an agent, and it is complete at launch (PRD FR-A4). The packages below install the same hooks and plugin code through each agent's own marketplace or registry, for users who look there first. Listing them is a post-launch follow-up and does not block a release.

Every file under `plugins/`, `packages/`, `.claude-plugin/`, `.agents/plugins/` and `.cursor-plugin/` is generated by `node tools/plugins/build.mjs` from the sources `setup` uses (`src/format/claude-settings.ts`, `opencode-plugin.ts`, `pi-extension.ts`), with the version from `package.json`. Do not edit them by hand. After changing a hook or bumping the version, run the generator and commit the result; `tests/plugins.test.ts` fails until you do.

A user who has both `setup`'s hooks and a package gets one injection per session start, not two: `prime --hook` deduplicates by agent, event and session (D057), and the OpenCode plugin and pi extension register only once per process.

All six packages need the `todopi` CLI on the user's regular `PATH` (a global install). The hooks call it; none of the packages bundles it.

## Gemini extension repository

A Gemini CLI extension's `gemini-extension.json` must be at the root of the repository (or release archive) users install from, and there is no install-from-subdirectory option. Putting it at the root of this repository would make every install clone all of todopi, so it gets its own repository:

1. Create the public repository `seandong/todopi-gemini` and add the GitHub topic `gemini-cli-extension` (the gallery at geminicli.com/extensions picks up tagged repositories daily).
2. Copy the contents of `plugins/gemini/` to its root, commit, and tag it with the same version as todopi.
3. On each todopi release that changes the Gemini hooks or version, copy again and tag.

One gap compared with `setup gemini`: `setup` also adds `AGENTS.md` to Gemini's `context.fileName`, which keeps the protocol line "when you notice your context was compacted, run `todopi prime`" in the system instruction. An extension can only name context files inside its own directory, so extension users are covered after `/compress` (the hooks re-inject) but not after an automatic compression. The extension's README (`plugins/gemini/README.md`, generated) tells them to run `todopi setup gemini` in the project as well, or add `AGENTS.md` to `context.fileName` themselves.
