## 修什么

- frontmatter 的键顺序与引号形态：交给唯一的发射器 `emitFrontmatter`（未知键原样保留）。
- 时间戳：带时区偏移或小数秒、但无歧义的 RFC 3339 → UTC 秒级 `Z`（小数向下截断）。没有时区的不猜。
- 验收标准的 `[X]` → `[x]`：只动 parseAcceptance 认出的行。
- rank 回填：缺 rank 的任务按 §7.4 的现有顺序排在有 rank 的那一段之后——显示顺序不变。
  rank 不是字符串（`rank: 7`）的不算缺，那是要人看的错。
- 过期租约：心跳超过 `lease_hours` 的删掉（§8：运行时状态，随时可删）。

## 不碰什么（用户 2026-09-26 定，规格 §6.3 加例外）

- **`updated` 不刷新。** 它是跨机器的心跳（§7.3）；修复工具刷新它，跑一次 `--fix` 所有过期认领都会
  看起来又活了。
- **Log 一个字节都不动**，哪怕某一行解析不了（FR-Q1）。
- 读不出来的文件不修，照常由 doctor 报告。
