# F22 agent 环境推断身份（FR-C4）实现计划

**任务：** `tp-h2mxiu`。**Spec:** PRD FR-C4、FR-C6；DECISIONS D014、D035、D043。

## 先核实的外部事实

六家 agent 给自己工具子进程设的环境变量，逐家一手证据（表见 D043）：Claude Code 本会话实测；Codex 让它用 shell 工具 `env`；
Gemini、pi、Cursor 读安装包源码；OpenCode 用本地假 OpenAI 服务器回 bash 工具调用在真实运行时里 `env`。同时确认这些变量
不一定出现在钩子子进程里 → 钩子要显式带 `--agent`。

## 组成

1. `domain/actor.ts`：`AGENT_SIGNALS`（顺序即优先级，Claude Code 最后）、`agentFromEnv`、`resolveActor` 的第三级 `<agent>@<host>`。
2. `commands/actor.ts`：`currentAgent`（`TODOPI_AGENT` 显式优先、名字校验，其次环境信号）。
3. `cli.ts`：全局 `--agent <name>`（preAction 放进 `TODOPI_AGENT`）。
4. `format/claude-settings.ts`：四种配置的钩子命令带 `--agent`；旧版标准组就地改写；被改过的旧组提示。插件与扩展传 `--agent`。
5. 测试隔离：身份相关的单元测试与全部 e2e 清掉 agent 信号。
6. `tools/e2e/f22-actor-env.sh`：六家信号、嵌套、覆盖顺序、拼错的名字、钩子与工具同一 actor（严格匹配的 release）。
