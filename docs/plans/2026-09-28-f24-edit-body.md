# F24 建好之后改验收标准与 Plan、`--edit` 实现计划

**任务：** `tp-anx7e2`。**Spec:** PRD FR-T4、§8（add / edit 的参数）、spec §5.3.2（验收标准的编号与原样保留）；v0.1 缺口审计。决策见 D045。

1. `domain/sections.ts`：`replaceSection`（Acceptance Criteria / Plan 整段换掉，缺失时按小节顺序插入，空文本删掉小节）；
   `editCriteria`（按编辑前的编号 set / remove / add；已勾选、越界、多行、空文本抛错；只动标准那几行，嵌套项与非复选框行不动）。
2. `domain/edit-buffer.ts`：编辑器里的那一页（`# 标题`、说明行、三个小节）与读回；标题为空当放弃。
3. `exec/editor.ts`：`$VISUAL` / `$EDITOR` / `vi`，stdin 与 stdout 都要是终端；启动失败、非零退出抛 `EditorError`。
4. `commands/edit.ts`：`--plan`、`--ac-add` / `--ac-set` / `--ac-rm`、`--edit`。写完问一遍解析器：改到的小节读回恰好是给的，没改的小节
   （含 Log）读法一个字节不变，没有新的未闭合块；整段换掉验收标准时已勾选项原样。
5. `commands/add.ts`：`--plan`、`--edit`（标题可以留到编辑器里写；验收标准只能是未勾选的复选框行）。
6. 测试：`tests/commands/edit-body.test.ts`（含变异测试补的：一次删两条、Plan 截断、夹带 `## Log`）；
   `tools/e2e/f24-edit-body.sh` 经 `script(1)` 给伪终端，真的跑一个 `$VISUAL` 脚本（macOS 与 util-linux 两种 script 都验过）。
