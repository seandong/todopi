# F19 `import <plan.md>` 实现计划

**任务：** `tp-medxth`（旧 F19）。**Spec:** PRD FR-I1；格式规格 §5.3.3（`created source=`）；D031、D040。

## 组成

1. `markdown/checklist.ts`：`parseChecklist(md)` → 标题与 checkbox 条目的树（CommonMark AST；代码块不算；纯文本；
   分隔线结束一级以下的小节）。
2. `domain/import-plan.ts`：`planImport(tree)` → 前序的待建任务（身份键、父级键、标题截断、closed 判定、警告）；
   `importedKeys(tasks, source)` 从账本认出同一来源已导入的任务，键算法与 planImport 相同。
3. `format/write.ts`：抽出 `createTaskUnlocked`（调用方持锁）；`emit.ts` 的 NewTask 加 `resolution`。
4. `commands/import.ts`：读文件（非法 UTF-8 拒绝）、来源路径编码、一把锁里按键跳过已有、新建其余。
5. `output/dto/import.ts`、`output/render/import.ts`、`cli.ts` 的 `import <file>`。
6. `tools/e2e/f19-import-md.sh`。

## 要用例钉住的

- 解析：层级、嵌套条目、普通项目符号下的条目、代码块 / 缩进代码 / `[ ]` 无空白 / 列表项里的标题都不是条目；纯文本。
- 映射：空标题剪掉且不占序号；同名序号；前序；closed 规则（全勾才关、混合按全部子项）；200 字符边界。
- 导入：parent、rank = 文档顺序、closed/done forced=true 与 Log、created source、doctor 通过、ready 队列。
- 幂等：重复导入一个字节都不变；move 过的 rank 保留；新条目挂对父级、排最后。
- 来源编码、项目外绝对路径、不同来源互不影响、读不了 / 非 UTF-8 退出 1。
- e2e：两个进程同时导入只建一份。
